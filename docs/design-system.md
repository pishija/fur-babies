# Design System

## Overview

FurBabies uses a two-layer design token pipeline:

```
Pencil (.pen file)
    ↓  npm run extract (scripts/extract-from-pencil.js)
design-tokens/tokens/*.json   ← source of truth, committed to git
    ↓  npm run tokens (Style Dictionary)
FurBabies/Shared/Theme/Generated/GeneratedTokens.swift   ← auto-generated, committed to git
    ↓  imported by
FurBabies/Shared/Theme/Theme.swift   ← hand-written semantic wrapper, never auto-generated
    ↓  imported by
All SwiftUI views
```

**Rule:** Views only import `Theme`. They never reference `GeneratedTokens` directly.

---

## Updating tokens from Pencil

When design decisions change in Pencil, run both scripts from the project root:

```bash
swift design-tokens/ExtractFromPencil.swift path/to/FurBabies.pen
swift design-tokens/GenerateTheme.swift
```

Then commit both the updated `tokens/*.json` files and `GeneratedTokens.swift`.

No dependencies. Both scripts use only `Foundation`, which ships with macOS.

## Token categories

### Colors — `design-tokens/tokens/color.json`

| Group | Tokens | Purpose |
|---|---|---|
| `brand` | `primary`, `secondary`, `accent` | Core brand palette |
| `background` | `default`, `surface`, `muted` | Screen and card backgrounds |
| `text` | `primary`, `secondary`, `tertiary`, `inverse`, `onBrand` | Text hierarchy |
| `border` | `default`, `strong` | Dividers, outlines |
| `status` | `error`, `success`, `warning`, `info` | Feedback states |

### Typography — `design-tokens/tokens/typography.json`

Font sizes (in points) and font weights. Font sizes mirror Apple's Dynamic Type scale names.

| Token | Value |
|---|---|
| `caption` | 12 |
| `footnote` | 13 |
| `subheading` | 15 |
| `callout` | 16 |
| `body` | 17 |
| `headline` | 17 |
| `title3` | 20 |
| `title2` | 22 |
| `title1` | 28 |
| `largeTitle` | 34 |

Font weights: `regular` (400), `medium` (500), `semibold` (600), `bold` (700).

### Spacing — `design-tokens/tokens/spacing.json`

4-point grid. All values in points.

| Token | Value |
|---|---|
| `xxs` | 4 |
| `xs` | 8 |
| `sm` | 12 |
| `md` | 16 |
| `lg` | 24 |
| `xl` | 32 |
| `xxl` | 48 |
| `xxxl` | 64 |

### Corner radius — `design-tokens/tokens/radius.json`

| Token | Value |
|---|---|
| `sm` | 8 |
| `md` | 12 |
| `lg` | 16 |
| `xl` | 24 |
| `full` | 999 (pill shape) |

## Generated file

`FurBabies/Shared/Theme/Generated/GeneratedTokens.swift` is auto-generated by Style Dictionary. Never edit it by hand. Its structure:

```swift
// AUTO-GENERATED — do not edit directly.
import SwiftUI

enum GeneratedTokens {
    enum Color {
        static let brandPrimary = Color(.sRGB, red: 0.910, green: 0.384, blue: 0.165, opacity: 1)
        static let backgroundDefault = Color(.sRGB, red: 0.980, green: 0.980, blue: 0.973, opacity: 1)
        // ...
    }
    enum Spacing {
        static let md: CGFloat = 16
        // ...
    }
    enum FontSize {
        static let body: CGFloat = 17
        // ...
    }
    enum FontWeight {
        static let semibold: CGFloat = 600
        // ...
    }
    enum Radius {
        static let md: CGFloat = 12
        // ...
    }
}
```

## Theme.swift — the wrapper agents use

`FurBabies/Shared/Theme/Theme.swift` is hand-written and provides semantic aliases over `GeneratedTokens`. This is the only file agents should import in views. It is updated by a human (or agent) when new semantic roles are needed — not auto-generated.

```swift
import SwiftUI

enum Theme {
    enum Colors {
        // Brand
        static let primary    = GeneratedTokens.Color.brandPrimary
        static let secondary  = GeneratedTokens.Color.brandSecondary
        static let accent     = GeneratedTokens.Color.brandAccent

        // Backgrounds
        static let background = GeneratedTokens.Color.backgroundDefault
        static let surface    = GeneratedTokens.Color.backgroundSurface
        static let muted      = GeneratedTokens.Color.backgroundMuted

        // Text
        static let textPrimary   = GeneratedTokens.Color.textPrimary
        static let textSecondary = GeneratedTokens.Color.textSecondary
        static let textTertiary  = GeneratedTokens.Color.textTertiary
        static let textInverse   = GeneratedTokens.Color.textInverse
        static let textOnBrand   = GeneratedTokens.Color.textOnBrand

        // Borders
        static let border       = GeneratedTokens.Color.borderDefault
        static let borderStrong = GeneratedTokens.Color.borderStrong

        // Status
        static let error   = GeneratedTokens.Color.statusError
        static let success = GeneratedTokens.Color.statusSuccess
        static let warning = GeneratedTokens.Color.statusWarning
        static let info    = GeneratedTokens.Color.statusInfo
    }

    enum Typography {
        static let largeTitle  = Font.system(size: GeneratedTokens.FontSize.largeTitle,  weight: .bold)
        static let title1      = Font.system(size: GeneratedTokens.FontSize.title1,      weight: .bold)
        static let title2      = Font.system(size: GeneratedTokens.FontSize.title2,      weight: .semibold)
        static let title3      = Font.system(size: GeneratedTokens.FontSize.title3,      weight: .semibold)
        static let headline    = Font.system(size: GeneratedTokens.FontSize.headline,    weight: .semibold)
        static let body        = Font.system(size: GeneratedTokens.FontSize.body,        weight: .regular)
        static let callout     = Font.system(size: GeneratedTokens.FontSize.callout,     weight: .regular)
        static let subheading  = Font.system(size: GeneratedTokens.FontSize.subheading,  weight: .regular)
        static let footnote    = Font.system(size: GeneratedTokens.FontSize.footnote,    weight: .regular)
        static let caption     = Font.system(size: GeneratedTokens.FontSize.caption,     weight: .regular)
    }

    enum Spacing {
        static let xxs  = GeneratedTokens.Spacing.xxs
        static let xs   = GeneratedTokens.Spacing.xs
        static let sm   = GeneratedTokens.Spacing.sm
        static let md   = GeneratedTokens.Spacing.md
        static let lg   = GeneratedTokens.Spacing.lg
        static let xl   = GeneratedTokens.Spacing.xl
        static let xxl  = GeneratedTokens.Spacing.xxl
        static let xxxl = GeneratedTokens.Spacing.xxxl
    }

    enum Radius {
        static let sm   = GeneratedTokens.Radius.sm
        static let md   = GeneratedTokens.Radius.md
        static let lg   = GeneratedTokens.Radius.lg
        static let xl   = GeneratedTokens.Radius.xl
        static let full = GeneratedTokens.Radius.full
    }
}
```

## How agents use Theme in views

```swift
// Colors
.foregroundStyle(Theme.Colors.textPrimary)
.background(Theme.Colors.surface)
.tint(Theme.Colors.primary)

// Typography
Text("Hello").font(Theme.Typography.headline)
Text("Detail").font(Theme.Typography.body).foregroundStyle(Theme.Colors.textSecondary)

// Spacing
.padding(.horizontal, Theme.Spacing.md)
.padding(.vertical, Theme.Spacing.sm)
VStack(spacing: Theme.Spacing.xs) { ... }

// Radius
.cornerRadius(Theme.Radius.md)
.clipShape(RoundedRectangle(cornerRadius: Theme.Radius.lg))
```

**Never** use raw hex values, hardcoded numbers, or system colors in views. Everything goes through `Theme`.

## Pencil variable naming convention

For the extraction script to map Pencil variables correctly, name variables in Pencil using this convention:

| Token type | Pencil variable name format | Example |
|---|---|---|
| Brand color | `--color-brand-{name}` | `--color-brand-primary` |
| Background color | `--color-background-{name}` | `--color-background-surface` |
| Text color | `--color-text-{name}` | `--color-text-secondary` |
| Border color | `--color-border-{name}` | `--color-border-default` |
| Status color | `--color-status-{name}` | `--color-status-error` |
| Spacing | `--spacing-{name}` | `--spacing-md` |
| Font size | `--font-size-{name}` | `--font-size-body` |
| Font weight | `--font-weight-{name}` | `--font-weight-semibold` |
| Radius | `--radius-{name}` | `--radius-lg` |

---

## Adding a new token

1. Add the variable in Pencil with the correct naming convention
2. Run `swift design-tokens/ExtractFromPencil.swift path/to/FurBabies.pen`
3. Run `swift design-tokens/GenerateTheme.swift` → `GeneratedTokens.swift` is updated
4. Add a semantic alias in `Theme.swift` if needed
5. Commit `tokens/*.json`, `GeneratedTokens.swift`, and `Theme.swift`

## Changing a token value

Only change values in Pencil, then run both scripts from the project root. Never change values directly in `tokens/*.json` or `GeneratedTokens.swift` — they will be overwritten on the next extract run.

---

## Dark mode

Not in v1. The token pipeline is designed to support it in v2: add a `color.dark.json` token file with overrides, and update the Style Dictionary config to generate `Color(light:dark:)` pairs. `Theme.swift` does not need to change.
